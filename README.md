# House Price Prediction (From Scratch)

This repository contains sample Python code to predict house prices without relying on high-level, built-in machine learning libraries like `scikit-learn`. The core algorithms are implemented entirely from scratch to demonstrate the underlying mathematical mechanics of predictive modeling.

## Features

* **Custom Algorithm Implementation:** Machine learning models (e.g., Linear Regression) built from scratch using foundational math.
* **Gradient Descent Optimization:** Includes a custom training loop to iteratively minimize the cost function.
* **Manual Data Preprocessing:** Custom functions for feature scaling, normalization, and data splitting.
* **Evaluation Metrics:** Scratch-built calculators for Mean Squared Error (MSE) or R-squared metrics.

## Prerequisites

While high-level ML libraries are avoided, you will need the following basic Python packages for data manipulation and matrix operations:

* Python 3.x
* NumPy 
* Pandas 
* Matplotlib (optional, for visualization)
